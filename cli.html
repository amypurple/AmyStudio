LOCAL AND AUTOMATED BUILDS

AMY COMPILER CLI

Compile an ordinary .alexis source with the same compiler and Z80 assembler used by Amy Studio.

node tools/amyc.mjs game.alexis --output --asm --opt balanced

AUTHORITATIVE HELP

Ask the compiler you are running.

The command below always describes the exact options and values supported by your checkout:

node tools/amyc.mjs --help

OUTPUTS

Choose only the artifacts you need.

OptionResult
--output [path]ColecoVision ROM or ADAM binary; --rom remains an alias.
--asm [path]Generated Z80 assembly.
--optimized-asm [path]Assembly after optimizer passes.
--symbols [path]Debugger symbols.
--report-json pathMachine-readable result and diagnostics.

When an optional path is omitted, the file is written beside the source. Output directories are created automatically.

PROFILES

Optimization is explicit.

ValuePurpose
autoSafe for Tiny Sound sources, Balanced otherwise.
offNo assembler optimization; useful for debugging.
safeConservative local optimization.
balancedRecommended size and safety balance; CLI default.
aggressiveMore speculative optimization; validate the ROM.
experimentalLeast conservative; requires runtime testing.

TARGETS AND MEMORY

ColecoVision and ADAM builds.

Targets: colecovision-cartridge, colecovision-megacart, adam-native-program, adam-disk, adam-data-pack.

Memory profiles: colecovision-cartridge, colecovision-megacart, colecovision_legacy_sdcc, adam-eos-application, adam-os7-eos-drivers.

ADAM medium: --medium dsk or --medium ddp. The single-source CLI emits the program payload; complete multifile media packaging remains an Amy Studio project operation.

PROJECT OPTIONS

Assets, hardware, and symbols.

--project-dir dirResolve @project/... and project ASM includes.
--hardware idRepeatable: sgm, sgm1, adam-sound-enhancer, adamlink, eve-serial, orphanware-serial, micro-serial, microinnovations-serial.
--define symbolAdd a compile-time symbol; repeat as needed.

Unknown options and invalid values are rejected instead of being ignored. For advanced compiler-development switches and current details, use --help or read the complete CLI reference.
