# Deepwarden keypad overlay

The overlay exposes the three standard-controller keypad commands used by the
current Deepwarden source:

- `1`: drink a potion;
- `*`: open the hero sheet;
- `#`: open the floor map.

`deepwarden-keypad-overlay.svg` is the printable master. The 1008x1200 PNG is a
2x raster preview and distribution copy. Both preserve the 504:600 proportions
of the Mouse Trap reference overlay supplied for physical alignment. Print the
SVG at the dimensions of a known ColecoVision keypad overlay rather than sizing
it from screen pixels.

The artwork is original to Deepwarden. The Mouse Trap image was used only as a
geometric reference for the keypad grid, rounded body, and controller cutouts.
