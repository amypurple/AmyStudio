# Zombie Botte Poulet r5.3

An original ColecoVision game by Amy & Claude (2026), with three seasonal
acts and Ninja mode. This full 64 KiB MegaCart edition is separate from
the standalone Act I example.

`zombie-botte-poulet.rom` is the supplied release ROM. The original ZIP
contains the build scripts, source templates, assets and validation report.
Use the project's build script rather than compiling its template directly.
