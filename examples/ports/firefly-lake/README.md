# Firefly Lake v2

An original English-language ColecoVision pinball game by Amy & Claude
(2026), distinct from the Ahoy! adaptation Flipper Alley. Light FIREFLY
to trigger Swarm mode and shoot the ramp for the jackpot.

The left and right fire buttons operate their respective flippers.
Pull down to launch; use left, right, or up to nudge.

`flipper.alexis` is the generated standalone source; `flipper.rom` is
the supplied 30,088-byte ROM built with Amy Studio r12.11, balanced.
